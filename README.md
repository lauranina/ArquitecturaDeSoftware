# Actividad 10: Aplicación de Patrones de Diseño (GoF)

## 1. Descripción del Proyecto
Este proyecto implementa un **Sistema de Gestión de Riego de Plantas** en Java para consola, aplicando tres patrones de diseño del libro de GoF (*Gang of Four*) para estructurar el control de riego y la emisión de notificaciones.

El sistema permite gestionar el inventario de plantas, evaluar de forma automatizada cuándo requieren hidratación según su frecuencia predefinida y notificar a los encargados mediante avisos estándar o urgentes.

## 2. Tecnologías Utilizadas
- **Lenguaje:** Java (JDK 17 o superior)
- **Paradigma:** Programación Orientada a Objetos (POO) y Principios SOLID
- **Entorno:** Consola / Terminal

## 3. Instrucciones de Compilación y Ejecución
javac SistemaPlantas.java
java SistemaPlantas
